About

Who keeps this archive and where it goes next

Who I am

I'm a computer science student focused on systems, the software that everything else runs on, from operating systems to how programs actually execute. I like knowing how things work underneath, and I want to understand a tool well enough to trust it.

AI is the field I keep coming back to, because it is changing what software can do faster than anything else I study. I care about where technology is headed, and I'd rather help build it than watch it happen.

Why this was made

This is my portfolio: one place for the things I build. Writing down what each project is, how I made it and what I learned turns a pile of finished work into a record I can look back on and show others.

The portfolio is one of its own entries, so it documents itself. It is a plain front-end page with no server and no database, and its source is on GitHub.

Future goals

  • Add each new project to the archive as I finish it.
  • Keep notes on what changed between versions of each project.
  • Review generated code for mistakes before I rely on it.
  • Build one larger project that combines several of these.
